# Проверка backend MVP

Прогон: 09.09.2026, macOS 26.6.2 ARM64, 8 CPU, Python 3.11.5; зависимости из `uv.lock`. API-контракт 1.0.0.

| Проверка | Результат |
|---|---|
| `uv run pytest -q` | 95 passed; одно предупреждение устаревшего API в Starlette TestClient |
| `uv run ruff check backend` и `uv run ruff format --check backend` | PASS |
| OpenAPI, path-параметры и реальные HTTP-ответы | PASS; исправлен query-параметр company_id у списков партий и карантина |
| API по TCP и отдельные процессы worker | PASS; партия пережила logout и перезапуск, повтор ключа сохранил ответ |
| Две одновременно принимаемые партии с общим файлом | PASS; один claim/перенос, второй исход ALREADY_PROCESSING |
| Реальная файловая песочница | PASS; no-replace, ссылки, изменения источника, карантин, восстановление intent |
| Прерванные seed и индексирование | PASS; продолжение после checkpoint, публикация полного поколения |
| Wheel, установленный в отдельное окружение вне репозитория | PASS; init-demo, tick, status, загрузка всех 33 операций |

Поиск измерен командой `uv run python backend/benchmarks/search.py`: 3200 добавленных файлов и стандартный seed двух компаний, 5 прогревочных и 40 измеряемых запросов каждого класса. FastAPI TestClient работает в одном процессе, без сетевой задержки и параллельной нагрузки.

| Сценарий | Совпадений | p50 | p95 |
|---|---:|---:|---:|
| `benchmark` + маркеры Archive/Atlas | 1600 | 105,567 мс | 115,194 мс |
| Широкий `bench` | 3200 | 129,539 мс | 143,503 мс |

Полный scan: 1011,552 мс; generation `generation-6b5d383f57f7caef7aeca821`. Эти цифры относятся только к данному локальному синтетическому корпусу.

Не проверены: frontend/mock/E2E и полная совместная приёмка Q-001…Q-045, Linux runtime, Windows, Docker, производственная инфраструктура и нагрузка 50 пользователей. Прохождение backend-тестов не заменяет эти уровни приёмки.
